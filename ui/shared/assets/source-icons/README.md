# External source icon assets

These images are vendored locally so source identification works offline and does not depend on third-party CDNs.

- `synology-photos.png` — Synology Photos application/package icon, sourced from `homarr-labs/dashboard-icons`.
- `synology-file-station.png` — Synology File Station application/package icon, sourced from `homarr-labs/dashboard-icons`.
- `yike-photos.png` — 一刻相册 (`com.baidu.youavideo`) application icon, sourced from the public `zirawell/R-Store` icon set.

The corresponding product names, logos, and trademarks belong to their respective owners. xDrive uses these assets only to identify the external service selected by the user.
