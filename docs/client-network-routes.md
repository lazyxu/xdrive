# Android / Desktop 内外网连接

客户端不修改系统 hosts、DNS 或证书库。高级选路使用同一个 HTTPS **域名**地址，例如 `https://drive.example:8443/`；连接 IP 只决定 TCP 目的地，HTTP Host、TLS SNI 和证书验证仍使用原域名。它不是关闭证书验证，也不会把地址改写成 IP URL。

## 配置

- **自动**：填写内网 IP 后，先匿名验证内网；连接拒绝、超时或网络不可达时尝试公网。证书、域名、重定向或版本响应错误立即停止，不回退。
- **仅内网**：必须填写 RFC1918 私有 IPv4 或 ULA IPv6；不会尝试公网。
- **仅公网**：不会尝试内网。可显式填写公共 IP；留空时使用 DNS，并拒绝解析得到的私有、回环和保留地址。

Desktop 公网 DNS 直接使用已配置的 DNS 服务器，不走 Windows hosts。Android 使用设备自己的 DNS，不会继承 Windows hosts。若网络 DNS 本身提供分流内网结果，“仅公网”需要另填实际公网 IP；没有内置第三方公共 DNS。公网 IP 变化后可清空该字段重新解析。

“自动 + 两个 IP 留空”保留原连接行为，兼容原来的 HTTP 明确允许、直接 IP 地址及 Desktop 已批准的私有 IP 根 CA 流程。需要内外网选路时请使用 HTTPS 域名；服务器证书必须覆盖这个域名，并受客户端正常信任。

## 切换边界

连接/登录前通过无 Cookie、无账号凭据的有界版本探测选择连接 IP。登录、后台客户端和 Desktop 同源签名预览都使用选定 IP；真实请求仍独立验证 TLS。偏好按服务器源隔离，登录凭据不属于选路设置。

这是**连接时自动选路**，不是活动会话任意网络间无缝漫游。离开内网或公网地址改变后，请重新连接/登录。不会因为密码错误、丢失响应或网络断开而自动把登录、上传等请求再发到另一条路径，也不宣称跨网络上传续传已验证。

## 错误和验证范围

客户端分别提示域名解析、连接/端口、超时、HTTPS 验证和无效响应，错误不包含原始响应、密码或 Token。诊断端口拒绝发生在 TLS 之前，不能据此归因于证书或密码。

2026-10-25 原现场：Windows hosts 指向内网，MuMu 实测使用公网 DNS；两端强制正确内网 IP 时端口均拒绝连接。修复覆盖解析差异和安全选路，但测试服务器/模拟器 fixture 通过不等于生产账户实际登录成功。部署可用性必须另行实际确认。
