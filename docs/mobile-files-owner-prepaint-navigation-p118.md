**Base:** lazyxu/xdrive master at 8fe74d12e659a95c2bdd71c4b13a42c7b34f775f. This is a tightly scoped follow-on to the merged P62/P78/P99/P104/P107/P109/P111 navigation work. It does not revert those fixes.

## Source-confirmed residual defects

1. **Recent → already accepted current folder with concurrent upload/copy/delete.** `WebFileExplorer` intentionally passes two different statuses to Mobile: `loading` includes composite Search/FileOperation busy, whereas `directoryLoading` is the original CloudFiles directory read. `openExternalDirectory` still checked `!props.loading` to classify the *same* directory as committed. A successful Recent/Quick Access activation could then remain on the old rail, since neither crumbs nor the already accepted Range changed and the pending different-directory ticket never completed.
2. **Externally activated Search while on Recent/Favorites.** The Mobile rail switch used `useEffect`, which runs after the initial render has committed and can allow a stale intermediate page before the search presentation catches up. This is a visual lifecycle issue, independent of how fast the actual Search GET returns.

## Minimal changes

- Treat an already accepted same-folder Range as committed when its **directory Owner**, not unrelated operation work, is idle. Preserve the existing successful activation promise check and the different-directory counted first-Range gate; do not immediately navigate for an unverified folder.
- Switch only the external Search rail state effect to `useLayoutEffect` so the corresponding Mobile visual state settles before browser paint. Locally launched Search from Browse Home/Recent/Favorites **still waits for the owning verified count**. Do not introduce loading pages, API calls, timers or client-side directories.
- Keep the **same** Mobile virtual scroll DOM host and the existing cold 180px / Gallery 220px quiet geometry. Existing genuine Search/Trash progress, thumbnail network loading, file transfer progress, retry/error, Gallery/Places and Wide Web/Desktop remain unchanged.
- Mounted original `MobileFiles` regressions in `desktop/tests/mobile-files-ios-runtime.cjs`: successful same-folder re-open while `loading=true, directoryLoading=false`, persistent quiet beyond 300ms and unchanged TestInstance identity; external Search from Favorites with original scroll host, before-paint source contract and verified count semantics.
