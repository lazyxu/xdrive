# 图库地点双模式（2026-10-23）

默认 Web/Mobile Web/PWA 的同页原型：BMap.Map + ClusterLayer、官方 Convertor、Owner GPS 聚合代表点（有界 64 样本）、照片封面、原有照片墙和 Viewer。

切换按钮：**同页原型（默认） / 安全隔离版**。使用 `places_map_mode=isolated` 与 `location.replace()`，保留其它 Gallery URL 参数与 hash；不能在加载旧第三方 SDK 后仅通过 React 热切换进入安全版。

签名安全版仍由独立 HTTPS Child 承载，保留签名准入、Owner/Consent、Origin/CSP、Ticket/Cookie 与 BD09 可信 Cell/Range；发布被拒时绝不自动降级，也不恢复已退役的 Static PNG。

Desktop Electron `file:` 只使用独立 HTTPS 安全窗口，不在 Electron 文档引入 Browser AK SDK，不重建旧 Agent 原型 IPC。

**共用：** Gallery 业务层、Account 范围、BD09 相机回调、缩略图、原有虚拟化照片墙、Viewer 与地点导航。SDK 生命周期独立。

**差异：**旧版以 WGS84 代表点经官方转换，放大进入附近照片使用保守 WGS84 查询包络，不等于安全版当前 BD09 精确授权 Camera Range、Count/Timeline/Anchor；不可把前者冒充后者。

**风险：**旧版第三方脚本执行于主文档，不具备独立 Origin 隔离。Browser AK 不是 Server AK。严格 CSP 部署可能拒绝旧版资源；不得隐式放松 Child CSP。

**未完成：**旧版授权数据集合与精确 Range 对齐、真实百度 SDK/CSP/站点权限、iOS27 与 100k 配对性能。用户不能接触的生产环境安全验收：按用户决定跳过（未验收），代码级测试仍须通过。

## 旧同页原型追加收口：视窗附近照片操作

- 地图下方提供 **查看当前地图附近照片**，仅在用户完成地图交互、缩放足够且当前 SDK 视窗可以产生有限保守 WGS84 包络时可点。点击重新读取当前 camera，不使用异步过期快照。
- 无效/抛错的 SDK 相机不会被静默替换成全球 Owner SQL 范围；清除旧点和上一轮缩略图，并允许下一次真实交互重新查询。
- 这个按钮仅返回已有 Owner Gallery 的 `bbox` 附近查询，不称为**精确** BD09 当前相机范围。新版精确 Range 仍以 Server 已授权 BD09 索引与原图集为准。

## P0-01 · 旧版同页 GPS 明确授权

旧同页原型默认仍可显示百度动态底图，但不会自动调用 Owner GPS 概览，
也不会自动把 WGS84 照片定位代表点提交给百度官方 Convertor。
必须在同页明确点击「同意本次会话转换定位代表点」后，才会开始读取
Owner GPS 代表点并使用官方 SDK 转换。每个视窗最多返回 64 个有界代表点，
用户继续平移缩放时可能产生新的第三方坐标请求；不得将这个 64 解释成全会话总量。

授权仅为当前 React 地图组件的内存状态，不保存在 localStorage、
sessionStorage、Cookie、URL、Server 或第三方 Child 中；退出地图或切换账号后
需重新同意。「结束本次定位授权」强制刷新文档以停止当前第三方脚本会话，
不承诺撤回此前已提交给百度的网络数据。过滤、转换和失败都不会改变
原始 WGS84 PhotoAsset 元数据。

**安全界限：**本次门禁防止 xDrive 在用户未同意前主动读取并转换 GPS 代表点，
并不等于在主文档运行的第三方脚本已被安全隔离，也无法防御恶意 SDK
访问同文档可达状态。希望避免这种同页脚本风险时，应显式切换「安全隔离版」。
生产不可达验收仍是「按用户决定跳过（未验收）」；源码级和 CI 权限回归不能跳过。

## P0-16 · 旧版 SDK 手势开始即废弃旧坐标转换

旧版 `movestart/zoomstart` 已取消上一轮 Owner GPS 概览请求；现在同时
立即取消当前百度 Convertor 更新对应的 React `AbortController`，
防止旧相机转换完成后把之前的封面或聚合结果覆盖到新视窗。
在手势事件内不直接执行 ClusterLayer `setData`，避免干扰百度原生
`fitViewOnClick`；原有 `moveend/zoomend` 后 500 ms 稳定视窗机制不变。
已发送给第三方的坐标调用不能撤回、不能假定退还配额。

## P0 · 地图帧点击回执与模式选择保持可信

- 同页原型的原生 ClusterLayer 点击、照片封面按钮和打开照片墙统一要求当前存在已成功更新的 Owner 地图帧。手势开始、视窗变更、新一次转换启动时立即失效；仅最新转换并提交图层后恢复点击。避免旧聚合标记在跨城市拖动过程中误打开原位置的照片墙。
- 地图交互开始时还会禁用「查看当前地图附近照片」；只有新的 SDK 视窗稳定并校验成功后才重新启用，避免移动中误用上一帧范围。
- URL **不带** `places_map_mode` 时默认同页旧原型；参数重复、未知、空值、非 HTTP(S) 或解析失败时保守选择隔离版，不能因手写链接错误而隐式降级。点击旧原型按钮则删除该参数，显式返回默认行为。

## 旧原型全球视窗与加载失败重试

- 原生百度地图缩放 3–4 时，合法的全球经度范围 `-180…180` 可继续读取已经明确 GPS 授权的 Owner 全球 64 代表点概览，避免用户拖动地图后整个照片层消失。超过该缩放级别时不能用全球查询替代受限视窗。
- 世界视窗必须来自有限、规范、没有抛错的官方 SDK `getBounds()`，不能从损坏/缺失视窗推断；WGS84 仅是展示概览，不是 BD09 照片精确 Range。
- Server Owner 概览请求失败时可点「重试当前视窗」。新的 effect 请求会取消旧请求，不会重载浏览器，也不会自动授予或持久化 GPS 授权。
