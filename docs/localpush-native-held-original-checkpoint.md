## Implemented narrow library contract

The new internal LocalPush `WithHeldCurrentOriginalReadCheckpoint` only receives an Agent-local RootGrant, exact persisted CURRENT journal hash, relative path, original content digest and bounded <=64MiB file size, plus a required **read-only** checkpoint. It resolves the file from a complete verified persisted CURRENT journal and requires a strong, single-link, unique native identity; it refuses caller-manufactured inventory items. It verifies the RootGrant is saved for the exact Server/account/device/Source, reads the original with the production safe Linux `openat2` or Windows nonreparse descriptor, and keeps this *same file handle open while checkpoint runs*. It rehashes the **same descriptor** afterwards, checks path/inode/native identity, persisted Root grant and unchanged complete CURRENT journal, and fails closed on any detected drift. All observation fields have `json:"-"`; no path, key, Root, Source or bytes can serialize to Web/Electron. Context cancellation is propagated.

The old `streamVerifiedInventoryFileBytes` read/copy behavior is preserved byte-for-byte for callers with no checkpoint; a private opt-in shared internal helper supplies the held callback path. Original staging semantics are unchanged.
