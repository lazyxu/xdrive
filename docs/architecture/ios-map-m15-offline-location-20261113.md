# M15 iOS 相册地图：定位超时与离线恢复

第一阶段在现有 CoreLocation 原生定位路径上增加 **15 秒有界单次超时**。只有用户显式点「我的位置」才启动 CLLocationManager 和超时计时器。取消、权限拒绝、正常结果及页面关闭均注销计时器；旧的请求/超时不能影响新的定位请求。无 GPS/地铁隧道/飞行模式场景不再永久旋转等待。

**仍未完成的部分**：真实 MapKit 底图瓦片失败与恢复可视反馈、iOS 无网络/恢复后的 GPS 标记安全、极端 WGS84 地理坐标实机交互、模拟器与真机网络故障注入。现有云端 Owner 错误处理仍需独立验收；不能将定位超时补丁宣称为 M15 全部完成。
