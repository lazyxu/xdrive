# P110 · Shared Wide FileExplorer has one non-reflowing feedback surface

## Source-confirmed regression
The original shared `ui/shared/src/mui/FileExplorer.tsx` mounted conditional selection capability reasons and `actionFeedback` as ordinary `flexShrink:0` children ahead of its single scroll host. The compact context panel also inserted unavailable-selection and selection-load messages. A failed search appended its error and retry row inside the search summary; a restored-position warning appended another in-flow row. Each late receipt could reduce the height of an already-visible 100k virtual list even though the directory and page were unchanged.

## Scope and remediation
P110 keeps the Web/Desktop shared `XDriveFileExplorer`, single `data-xdrive-file-explorer-scroll-host`, verified range/scroll anchors, Server authorization and original operation callbacks. It positions the existing root Paper, then moves **only transient receipts** into a single position-absolute, safe-area-aware, bounded overlay. The overlay has no flex size and does not handle pointer input except through its existing real interactive children. Its original selection reasons, operation outcome, unavailable-selection and selection-fetch status, search error/retry and saved-position retry remain readable. The Search summary, selection toolbar, actual selection progress and cancel, thumbnails/posters/Live Photos, transfers, virtualizer, search and Trash requests are not removed or delayed.

This is not a broad change to durable controls or loading state machines. The default cold first Range continues to be silent, while accepted rows and real media/network feedback remain truthful. The nested compact selection controls can still change when the user explicitly enters selection mode; do not claim that all possible geometry changes are eliminated.

## Regression/acceptance
The source-exact JSX ancestor test in `desktop/tests/file-explorer-wide-feedback-overlay-p110.cjs` requires one original feedback owner, no transient sibling in the context panel, real scroll-host identity and conditional messages/retry controls under the absolute owner. Existing Web and Desktop original component tests, 100k selection cancellation and original Gallery/Mobile P78-P109 suites must continue to pass. Exact new one-work HEAD requires its own 77+ full CI with Web/Desktop/Go API PostgreSQL Race/Linux/Windows/Rootless/artifacts and Final Gate, and fresh clean mergeability, before merge. Physical iOS Safari/Android/PWA/WAN and real 100k CLS/FPS are **NOT RUN**; no benchmark uplift is claimed.
