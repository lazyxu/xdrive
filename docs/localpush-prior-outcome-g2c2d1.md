## Safety / scope exclusions

No new uploading, Stage, Prepare, Bind, file COMMIT, cancellation, SourceRun,
key/claim deletion, next-generation mint, automatic retry, scheduler,
Renderer/Web/foreign Desktop IPC or NAS/Mirror activation.
The existing terminal POST MAY materialize only an immutable aborted/expired
SQL reservation row, never a file-terminal record. In particular an elapsed
30-second reservation lease does not prove that bytes are quiescent.

This is a prerequisite to later G2c2d durable physical file-terminal
COMMIT-vs-cancel exclusion, writer-quiescence and replayable terminal
receipts; verified, audited key/Stage claim retirement is a later
independent gate. Product enablement further requires SourceRun lifecycle,
owning Desktop control, multi-file and >=4GiB chunked backup and physical
installed Windows/Linux 1k/10k/100k interrupted E2E.
