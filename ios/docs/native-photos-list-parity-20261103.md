# iOS 原生照片列表对齐检查（2026-11-03）

范围：仅 iOS 原生图库列表（PhotoKit 本机照片、日期索引、相簿目录/详情、云端 PhotoAsset/备份原件网格与本机照片诊断入口）。不改 Viewer、地图、备份或其他平台。

设计原则：与 Apple 照片 App 相同的公共交互优先保持一致；xDrive 的来源切换、备份管理与五模块导航可以作为附加功能存在。所有列表用户可见部分**没有上一页/下一页**，内部仍使用 PhotoKit 64 项和 Server 48 项左右的按需窗口，避免 10 万张照片驻留内存。

## 仍有 UI/交互差距（未在本 PR 声称完成）

- P0：原生 **年／月／全部** 视图为有照片封面的内容网格，当前年/月依然只是按时间索引的文字列表；“日”可以作为 xDrive 的扩展。
- P0：图库和云端/本机来源仍是两套视觉结构，顶部来源胶囊条和备份状态行比 Apple 照片更占空间；需要在不改变五模块导航的前提下统一视觉层级。
- P0：按拍摄日期/加入日期排序尚未对齐；PhotoKit modificationDate 不是准确的加入日期，不应伪装。
- P0：视频持续时间标记、Live Photo 缩略图标记、照片/视频精确缩略图内容与 Apple 外观尚未全部核对。
- P1：原始比例网格切换、Square Grid、截图显隐、更多视图选项；当前只支持密度切换、照片类型过滤。
- P1：网格右侧快速年份/月份滚动定位、底部当前总数与筛选结果反馈、返回 Viewer 原格子恢复的细节。
- P1：多选态工具栏、滑动连续选择、跨窗口选择反馈、相簿成员排序、空状态/加载状态与动态字体。
- P1：本机/云端统一时间维度、超过 10 万媒体时的窗口滑动、权限/索引变化、iCloud-only 缩略图回退和横屏性能。
- P2：精选四季/事件的智能精选、收藏集/回忆/最近日期集合封面、系统动效与 VoiceOver 逐项对照。

验证界限：静态合同测试仅证明文件接线与基础约束；Xcode 构建、真机触摸/内存、实际 10 万张相册和性能对比必须独立验收。不得把本次 UI 差距清单视为功能已全部完成。
